# Project Vault Template

## First use
1. Open Obsidian → "Open folder as vault" → select this folder.
2. When prompted, choose "Trust author and enable plugins".
3. If plugins don't appear active: Settings → Community plugins → turn off Restricted mode, then enable Dataview and Templater.

## Main page
Open "Main page" first. It links to everything, project summary, contacts, links and lists monthly summaries and recent meetings. Rename the title for each project. Every template links back to it.

## Daily note
Click the calendar icon or run "Open today's daily note". It is created at Daily/YYYY-MM-DD.md (no subfolders).

## Meeting note
Create a note in Meetings/ named with the date first, e.g. `2026-11-10 Kickoff`, then insert the Meeting template ("Templates: Insert template" or "Templater: Open insert template modal"). The date in the file name is what places the meeting in the right month of the monthly summary. Fill in the Attendees section.

## Monthly summary
Create a note in Monthly/ named YYYY-MM (e.g. 2026-11), then insert the Monthly template ("Templates: Insert template" or "Templater: Open insert template modal").
The month is taken from the note's file name, so just name it correctly (YYYY-MM). Works with the core Templates plugin or Templater.
It lists completed and open tasks from Daily and Meetings, plus the month's meetings.
Tick tasks as `- [x]` for them to appear as completed.

## New project
Copy this whole folder (including the hidden .obsidian folder), rename it, and open it as a new vault.
